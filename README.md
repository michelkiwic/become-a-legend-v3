# Yoshi + Moshi — Become a Legend

Interactive one-page exhibition model for Yoshi + Moshi by Nina Staehli.

The six work groups can be explored directly in the model photograph. Hovering,
keyboard focus, or tapping a marker dims the surrounding image and highlights the
selected group with a contour and title.

## Local preview

Run `npm run dev` and open the local address shown in the terminal.

## Production build

Run `npm run build`.
